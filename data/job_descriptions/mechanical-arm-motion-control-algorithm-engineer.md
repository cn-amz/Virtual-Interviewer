# 目标岗位：机械臂运控算法工程师

> 这是项目第一版使用的占位 JD，用于 RAG、面试官追问策略和能力树虚拟树枝生成。后续可替换为真实招聘 JD。

## 岗位职责

- 负责机械臂运动控制、轨迹规划、抓取规划与控制策略开发。
- 参与机械臂系统集成、通信接口调试、控制参数整定和实机验证。
- 结合视觉感知、手眼标定、三维建图或目标检测结果，完成抓取和操作任务闭环。
- 针对双臂、多臂或协作机器人场景，设计动作下发、同步控制、碰撞规避和轨迹平滑策略。
- 参与仿真环境搭建与算法验证，包括 Gazebo、MoveIt、ROS / ROS2 或类似机器人开发框架。
- 跟进 VLA、Diffusion Policy、强化学习等机器人学习方法在机械臂任务中的应用。
- 对实机测试问题进行定位分析，输出调试记录、性能指标和优化方案。

## 任职要求

- 熟悉 Python 或 C++，具备良好的工程代码能力。
- 熟悉 ROS / ROS2、机器人运动学、路径规划、轨迹优化、控制理论基础。
- 熟悉机械臂标定、相机标定、手眼标定和视觉伺服相关流程者优先。
- 熟悉强化学习、模仿学习、VLA Policy、Diffusion Policy 或机器人抓取算法者优先。
- 熟悉 Gazebo、MoveIt、OpenCV、PyTorch、NumPy 等工具或框架。
- 具备机械臂实机部署经验，能独立分析通信、控制、标定、感知和执行链路问题。
- 有双臂、多臂协作、柔性物体操作或自主抓取项目经验者优先。

## 面试重点能力

- 机器人系统集成能力。
- 运动控制与轨迹平滑。
- 路径规划与抓取规划。
- 手眼标定与视觉感知闭环。
- ROS / ROS2 工程实践。
- 强化学习 / 模仿学习在机器人任务中的应用。
- 实机问题定位与指标化复盘。

## 能力树虚拟树枝

如果用户当前简历或面试回答中证据不足，可作为待提升节点：

- 控制器设计与参数整定。
- 碰撞检测与避障。
- 视觉伺服。
- 双臂协同任务分解。

- 工业机械臂通信协议与部署经验。
