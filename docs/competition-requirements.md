# 东南大学 AI+ 创新应用大赛要求摘要

信息来源：赛事内部需求页面（公开版本不保留内网地址）

抓取时间：2026-06-24

## 选择赛道

本项目选择：

**赛道一：AI Agent 应用创新赛**

赛道定位：

- 聚焦生成式 AI 在垂直领域的落地。
- 鼓励参赛者利用大语言模型（LLM）结合 RAG、Function Calling 等技术。
- 依托阿里云百炼平台。
- 通过零代码/低代码开发模式，解决科研、学习、生活中的具体痛点。
- 打造具有自主规划与执行能力的智能体（AI Agent）。

## 与本项目的匹配点

项目方向：实时通话型虚拟面试官。

匹配关系：

- 垂直场景：求职面试训练、科研/工程项目表达训练。
- LLM：Qwen-Omni-Realtime 作为实时面试官主模型。
- RAG：检索简历、项目经历、目标 JD、历史问答和面试记录。
- Function Calling：调用追问规划、回答评分、能力树更新、报告生成等工具。
- 多模态：支持语音输入、语音输出，后续可扩展摄像头观察候选人表达状态。
- 自主规划与执行：面试官根据阶段、用户回答和能力树自动追问。

## 核心任务

赛道一页面列出的核心任务：

1. 利用大语言模型（LLM）结合检索增强生成（RAG）技术。
2. 结合函数调用（Function Calling）实现工具调用能力。
3. 采用零代码/低代码开发模式，依托阿里云百炼平台。
4. 解决科研、学习、生活中的具体痛点场景。
5. 打造具有自主规划与执行能力的智能体。

## 作品要求

赛道一页面列出的交付物：

1. 项目策划书与设计方案。
2. Demo 视频，展示应用功能和效果。
3. 应用线上链接，可访问体验。

## 评分规则

赛道一评分项：

| 项目 | 权重 | 说明 |
| --- | ---: | --- |
| 应用创新性 | 30% | 技术方案的创新程度、RAG / Function Calling 的应用深度 |
| 技术实现质量 | 30% | 代码质量、系统架构、稳定性与可维护性 |
| 应用效果与体验 | 20% | Demo 演示效果、用户体验、问题解决能力 |
| 文档完整性 | 20% | 项目策划书质量、技术文档、演示视频 |

总分公式：

```text
总分 = 0.3 × 创新性 + 0.3 × 技术质量 + 0.2 × 应用效果 + 0.2 × 文档完整性
```

## 赛程

- 2026-06-01 至 2026-06-30：报名阶段。
- 2026-07-01 至 2026-07-05：技术培训周。
- 2026-07-06 至 2026-08-31：初赛。赛道一需完成全部应用开发和部署，提供 Demo 视频和应用线上链接。
- 2026-09 初：初赛结果公布。
- 2026-09：决赛路演暨颁奖典礼。每支队伍 10 分钟展示并接受评委提问。

## 对项目范围的影响

必须优先保证：

- 能公网访问或至少有可演示的线上链接。
- 有完整项目策划书和架构设计文档。
- Demo 视频能清楚展示实时面试、RAG、Function Calling、能力树复盘。
- 使用阿里云百炼能力作为主链路，而不是仅使用本地或第三方模型。

建议 MVP 保留：

- Qwen-Omni-Realtime 实时通话。
- 面试官状态机。
- 简历/JD RAG。
- Function Calling 工具路由。
- 面试后能力树与复盘报告。
- 公网发布/内网穿透接口。
